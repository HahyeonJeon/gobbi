## Implementation

- [network-deployment] How can new network behavior operate safely while peers still use earlier behavior?
  - **Owner:** Network Development transition owner
  - **Purpose:** Define mixed-version protocol deployment
  - **Oracle:** Old and new peers interoperate or reject safely, and convergence or compatibility evidence proves completion
  - **Activation evidence:** Accepted evidence establishes an owned network protocol with independently updated peers
  - **Source aliases:** network-deployment

- [network-diagnostics] Which operating evidence can an engineer collect without interrupting network service or exposing protected data?
  - **Owner:** Network Development diagnostics owner
  - **Purpose:** Collect bounded network evidence without disruption or protected-data leak
  - **Oracle:** A named engineer question is answered from bounded redacted evidence while service remains within accepted operation
  - **Activation evidence:** Accepted evidence establishes owned network operation or live non-disruptive diagnostics
  - **Source aliases:** network-diagnostics
