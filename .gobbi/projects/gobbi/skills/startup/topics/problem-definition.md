# Problem Definition Topics

Use this direct phase bank to prepare evidence-backed Problem Definition questions for the current subject.
Omit a question when accepted evidence already resolves its meaning. Preserve each distinct unresolved
question and any accepted neutral example.

## Project

- What stage is the Project in now?
  - **Example:** For example, distinguish an idea from a released Product.

- When Project sources disagree, which source has final authority over the Project's current purpose and direction?

- What happened in the most recent concrete occurrence of the Project-wide problem?

- What measurable cost, delay, error, or other consequence resulted from that occurrence?

- How often does the Project-wide problem occur?

- What evidence supports the current root-cause explanation for the Project-wide problem?

- What observation would show that the stated cause is itself caused by a deeper problem?

- What changed to make this the right time to act on the Project?

- Which Project assumption is most important to success and currently has the weakest evidence?

- Which risk could cause the greatest harm to the Project's intended result?

- What is the earliest observable sign that the highest-consequence Project risk is beginning to occur?

- What single action would do the most to prevent or limit that harm?

- What is the least costly reliable way to test the riskiest Project assumption?

- What Project result must remain true even if its Products or Implementations are rebuilt differently?
  - **Example:** For example, the intended result remains when a Product is replaced.

- What can be observed or measured now as the Project baseline?

- What measurable real-world change would show that the Project achieved its intended result?

- What technical result could satisfy the Project contracts but still fail affected people or consumers?
  - **Example:** For example, every check passes while affected people still cannot complete the outcome.

- What evidence would show that the Project should stop pursuing its intended result?

- Who could be significantly affected by the Project or its results without using a Product directly?

- Which people or consumers are intentionally outside the Project's current target group?

## Product

- What kind of independently useful application or platform is this Product?

- Which existing Products made by others already address this consumer problem?

- What happened in the most recent prior attempt to provide this Product outcome?

- Which person, group, or external system should use or consume this Product first?

- What important task or goal is that first consumer trying to complete with this Product?

- In what real situation does that consumer need the Product?

- What happens when the consumer cannot complete the task with the Product?

- What steps does the consumer take today without this Product?

- Which part of the current approach prevents or delays completion?

- What problem with the current approach would motivate the consumer to leave it?

- What Product benefit would motivate the consumer to try it?

- What concern could prevent the consumer from adopting this Product?

- What existing habit or workflow makes the current approach difficult to replace?

- What action shows that the consumer is willing to change from the current approach?

- Which result must this Product improve compared with the consumer's current approach?

## Implementation

- Which complete-stack constraint is mandatory rather than preferred, and why?

- Which external dependency is essential to this Implementation's Product result?

- Which Product result is lost or reduced if that dependency fails?

- Which license duty limits this Implementation's available stack alternatives?

- What ability to run or move the complete stack must this Implementation preserve, and what evidence proves success?
