# Problem Definition Topics

Use this direct phase bank to prepare evidence-backed Problem Definition questions for the current subject.
Each question records its semantic owner, purpose, oracle, activation evidence, source aliases, and any
accepted neutral example.

## Project

- [lifecycle-stage] What stage is the Project in now?
  - **Owner:** Project sponsor
  - **Purpose:** Classify current Project maturity
  - **Oracle:** Cited current evidence places the Project in one named maturity state
  - **Activation evidence:** Generally prepared; use accepted evidence when it already resolves this decision and ask only when unresolved.
  - **Source aliases:** lifecycle-stage
  - **Example:** For example, distinguish an idea from a released Product.

- [authoritative-project-source] When Project sources disagree, which source has final authority over the Project's current purpose and direction?
  - **Owner:** Project governance authority
  - **Purpose:** Resolve conflicting Project direction sources
  - **Oracle:** One named source is accepted as controlling and conflicting sources are dispositioned
  - **Activation evidence:** Generally prepared; use accepted evidence when it already resolves this decision and ask only when unresolved.
  - **Source aliases:** authoritative-project-source

- [last-problem-event] What happened in the most recent concrete occurrence of the Project-wide problem?
  - **Owner:** Affected-people representative
  - **Purpose:** Ground the Project problem in a recent event
  - **Oracle:** A dated or identifiable occurrence is recorded from evidence or testimony
  - **Activation evidence:** Generally prepared; use accepted evidence when it already resolves this decision and ask only when unresolved.
  - **Source aliases:** last-problem-event

- [problem-cost] What measurable cost, delay, error, or other consequence resulted from that occurrence?
  - **Owner:** Project outcome owner
  - **Purpose:** Quantify consequence of the observed problem
  - **Oracle:** The cited occurrence has a measurable or explicitly bounded consequence
  - **Activation evidence:** Generally prepared; use accepted evidence when it already resolves this decision and ask only when unresolved.
  - **Source aliases:** problem-cost

- [problem-frequency] How often does the Project-wide problem occur?
  - **Owner:** Project outcome owner
  - **Purpose:** Establish recurrence of the Project problem
  - **Oracle:** Evidence gives a count, rate, interval, or explicit unknown with collection plan
  - **Activation evidence:** Generally prepared; use accepted evidence when it already resolves this decision and ask only when unresolved.
  - **Source aliases:** problem-frequency

- [root-cause] What evidence supports the current root-cause explanation for the Project-wide problem?
  - **Owner:** Project evidence authority
  - **Purpose:** Select the supported causal explanation
  - **Oracle:** Cited evidence supports the cause and names material competing explanations
  - **Activation evidence:** Generally prepared; use accepted evidence when it already resolves this decision and ask only when unresolved.
  - **Source aliases:** root-cause

- [deeper-cause-test] What observation would show that the stated cause is itself caused by a deeper problem?
  - **Owner:** Project evidence authority
  - **Purpose:** Define evidence that would reopen root cause
  - **Oracle:** One observable result would falsify sufficiency of the stated cause
  - **Activation evidence:** Generally prepared; use accepted evidence when it already resolves this decision and ask only when unresolved.
  - **Source aliases:** deeper-cause-test

- [why-now] What changed to make this the right time to act on the Project?
  - **Owner:** Project sponsor
  - **Purpose:** Justify present intervention timing
  - **Oracle:** A dated change or constraint explains why action is warranted now
  - **Activation evidence:** Generally prepared; use accepted evidence when it already resolves this decision and ask only when unresolved.
  - **Source aliases:** why-now

- [riskiest-assumption] Which Project assumption is most important to success and currently has the weakest evidence?
  - **Owner:** Project risk owner
  - **Purpose:** Select the weakest load-bearing assumption
  - **Oracle:** Assumptions are compared by consequence and evidence strength; one is highest priority
  - **Activation evidence:** Generally prepared; use accepted evidence when it already resolves this decision and ask only when unresolved.
  - **Source aliases:** riskiest-assumption

- [material-risk] Which risk could cause the greatest harm to the Project's intended result?
  - **Owner:** Project risk owner
  - **Purpose:** Select the highest-consequence Project risk
  - **Oracle:** A named risk has a stated harmed result and consequence basis
  - **Activation evidence:** Generally prepared; use accepted evidence when it already resolves this decision and ask only when unresolved.
  - **Source aliases:** material-risk

- [risk-warning] What is the earliest observable sign that the highest-consequence Project risk is beginning to occur?
  - **Owner:** Project risk owner
  - **Purpose:** Define the earliest warning for the top risk
  - **Oracle:** A monitorable condition precedes or begins the risk event
  - **Activation evidence:** Generally prepared; use accepted evidence when it already resolves this decision and ask only when unresolved.
  - **Source aliases:** risk-warning

- [risk-mitigation] What single action would do the most to prevent or limit that harm?
  - **Owner:** Project risk owner
  - **Purpose:** Choose the primary risk-reduction response
  - **Oracle:** Evidence links one response to reduced likelihood or consequence
  - **Activation evidence:** Generally prepared; use accepted evidence when it already resolves this decision and ask only when unresolved.
  - **Source aliases:** risk-mitigation

- [assumption-test] What is the least costly reliable way to test the riskiest Project assumption?
  - **Owner:** Project evidence authority
  - **Purpose:** Choose the least-cost reliable assumption test
  - **Oracle:** The test has a result that supports or rejects the assumption at stated cost/confidence
  - **Activation evidence:** Generally prepared; use accepted evidence when it already resolves this decision and ask only when unresolved.
  - **Source aliases:** assumption-test

- [durable-outcome] What Project result must remain true even if its Products or Implementations are rebuilt differently?
  - **Owner:** Project sponsor
  - **Purpose:** Separate enduring outcome from current Products and stacks
  - **Oracle:** The outcome remains meaningful under hypothetical Product or Implementation replacement
  - **Activation evidence:** Generally prepared; use accepted evidence when it already resolves this decision and ask only when unresolved.
  - **Source aliases:** durable-outcome
  - **Example:** For example, the intended result remains when a Product is replaced.

- [current-baseline] What can be observed or measured now as the Project baseline?
  - **Owner:** Project measurement owner
  - **Purpose:** Record the pre-change comparison baseline
  - **Oracle:** A dated measure or observable condition can be compared with later results
  - **Activation evidence:** Generally prepared; use accepted evidence when it already resolves this decision and ask only when unresolved.
  - **Source aliases:** current-baseline

- [success-signal] What measurable real-world change would show that the Project achieved its intended result?
  - **Owner:** Affected-people representative
  - **Purpose:** Define real-world Project success
  - **Oracle:** A measurable affected-person or consumer change crosses an accepted success condition
  - **Activation evidence:** Generally prepared; use accepted evidence when it already resolves this decision and ask only when unresolved.
  - **Source aliases:** success-signal

- [misleading-success] What technical result could satisfy the Project contracts but still fail affected people or consumers?
  - **Owner:** Affected-people representative
  - **Purpose:** Guard against technical success without outcome success
  - **Oracle:** A technically compliant result is paired with an observable affected-person failure
  - **Activation evidence:** Generally prepared; use accepted evidence when it already resolves this decision and ask only when unresolved.
  - **Source aliases:** misleading-success
  - **Example:** For example, every check passes while affected people still cannot complete the outcome.

- [stop-evidence] What evidence would show that the Project should stop pursuing its intended result?
  - **Owner:** Project sponsor
  - **Purpose:** Define evidence for ending outcome pursuit
  - **Oracle:** One observable condition triggers a stop decision under named authority
  - **Activation evidence:** Generally prepared; use accepted evidence when it already resolves this decision and ask only when unresolved.
  - **Source aliases:** stop-evidence

- [affected-people] Who could be significantly affected by the Project or its results without using a Product directly?
  - **Owner:** Project stakeholder authority
  - **Purpose:** Identify materially affected non-consumers
  - **Oracle:** Each named group has a credible impact path from the Project
  - **Activation evidence:** Generally prepared; use accepted evidence when it already resolves this decision and ask only when unresolved.
  - **Source aliases:** affected-people

- [excluded-people] Which people or consumers are intentionally outside the Project's current target group?
  - **Owner:** Project sponsor
  - **Purpose:** Set the current target-population exclusion
  - **Oracle:** Excluded groups have a scope reason consistent with accepted outcomes
  - **Activation evidence:** Generally prepared; use accepted evidence when it already resolves this decision and ask only when unresolved.
  - **Source aliases:** excluded-people

## Product

- [software-type] What kind of independently useful application or platform is this Product?
  - **Owner:** Product authority

  - **Oracle:** Accepted Product evidence matches one independently useful application or platform form
  - **Activation evidence:** Generally prepared; use accepted evidence when it already resolves this decision and ask only when unresolved.
  - **Source aliases:** software-type

- [other-software] Which existing Products made by others already address this consumer problem?
  - **Owner:** Product discovery owner
  - **Purpose:** Identify existing external alternatives
  - **Oracle:** Named alternatives demonstrably address the same consumer problem
  - **Activation evidence:** Generally prepared; use accepted evidence when it already resolves this decision and ask only when unresolved.

- [prior-attempt] What happened in the most recent prior attempt to provide this Product outcome?

  - **Activation evidence:** Generally prepared; use accepted evidence when it already resolves this decision and ask only when unresolved.

- [task-situation] In what real situation does that consumer need the Product?

- [task-failure-cost] What happens when the consumer cannot complete the task with the Product?

  - **Activation evidence:** Generally prepared; use accepted evidence when it already resolves this decision and ask only when unresolved.

- [current-alternative] What steps does the consumer take today without this Product?

  - **Source aliases:** current-alternative

- [alternative-obstacle] Which part of the current approach prevents or delays completion?
  - **Owner:** Target-consumer representative

- [adoption-evidence] What action shows that the consumer is willing to change from the current approach?

## Implementation

- [hard-stack-constraint] Which complete-stack constraint is mandatory rather than preferred, and why?
  - **Owner:** Implementation technical authority
  - **Purpose:** Separate mandatory constraints from preferences
  - **Oracle:** Constraint has cited source, violation consequence, and binding status
  - **Activation evidence:** Generally prepared; use accepted evidence when it already resolves this decision and ask only when unresolved.
  - **Source aliases:** hard-stack-constraint

- [critical-dependency] Which external dependency is essential to this Implementation's Product result?
  - **Owner:** Implementation dependency owner
  - **Purpose:** Identify the dependency essential to Product outcome
  - **Oracle:** Disabling it demonstrably loses or degrades a named Product result
  - **Activation evidence:** Generally prepared; use accepted evidence when it already resolves this decision and ask only when unresolved.
  - **Source aliases:** critical-dependency

- [dependency-failure] Which Product result is lost or reduced if that dependency fails?
  - **Owner:** Implementation dependency owner
  - **Purpose:** Define Product impact of dependency failure
  - **Oracle:** Failure observation maps to a specific lost or reduced result
  - **Activation evidence:** Generally prepared; use accepted evidence when it already resolves this decision and ask only when unresolved.
  - **Source aliases:** dependency-failure

- [stack-license] Which license duty limits this Implementation's available stack alternatives?
  - **Owner:** Implementation licensing authority
  - **Purpose:** Constrain stack alternatives by license duty
  - **Oracle:** Cited license term permits, conditions, or excludes a stack choice
  - **Activation evidence:** Generally prepared; use accepted evidence when it already resolves this decision and ask only when unresolved.
  - **Source aliases:** stack-license

- [stack-portability] What ability to run or move the complete stack must this Implementation preserve, and what evidence proves success?
  - **Owner:** Implementation technical authority
  - **Purpose:** Set complete-stack portability obligation
  - **Oracle:** Named target move is demonstrated with required Product behavior preserved
  - **Activation evidence:** Generally prepared; use accepted evidence when it already resolves this decision and ask only when unresolved.
  - **Source aliases:** stack-portability
