# Evaluation Checklist

Mode: evaluation coverage register. Run style: do-confirm. The source stays unchecked. Audit a fresh filled copy against one evaluator report. Each row resolves PASS, FAIL with conformance finding IDs, or N/A with inspected evidence. Acceptance requires all applicable rows to PASS.

## Checks

- [ ] **EVAL-CK-01 [GATE] Frozen subject fidelity.** Claim: the report covers the complete creation package, scope, cases, checks, verification, and exact digest for one subject only. Applicability: unconditional. Pass: input ledger and digests reconcile. Evidence: paths, hashes, assignment, and report. On fail: the report is invalid. Sources: E-2–E-5, E-8; EVAL-SC-01.
- [ ] **EVAL-CK-02 [GATE] Fresh independent identity.** Claim: the evaluator is neither creator, persistent teammate, prior evaluator context, nor peer-report consumer. Applicability: unconditional. Pass: dispatch and provenance prove isolation. Evidence: identities, assignments, and access record. On fail: the report is invalid. Sources: E-1, E-7, E-11; EVAL-SC-02.
- [ ] **EVAL-CK-03 [GATE] Closed state and scoring.** Claim: findings, dispositions, confidence, severity, checklist links, section results, and report verdict obey the exact schema and thresholds. Applicability: unconditional. Pass: independent derivation matches. Evidence: JSON, schema, and scoring recomputation. On fail: the report is invalid. Sources: E-6–E-10; EVAL-SC-03.
- [ ] **EVAL-CK-04 [GATE] Complete unique report shape.** Claim: Project, Structure, Performance, Aesthetics, Usage, Consistency, Risk, and Overall each occur once, and every selected case and check is represented. Applicability: unconditional. Pass: machine and rendered structures agree. Evidence: validator, headings, IDs, and checklist. On fail: the report is invalid. Sources: E-3, E-5, E-6, E-9, E-13; EVAL-SC-04.
- [ ] **EVAL-CK-05 [GATE] Cost-independent rigor.** Claim: subject size or review cost removed no required system, evidence, lens, case, check, or fresh repeat. Applicability: unconditional. Pass: the complete required set is present. Evidence: input and coverage ledgers. On fail: the report is invalid. Sources: E-3–E-5, E-12, E-14; EVAL-SC-05.
- [ ] **EVAL-CK-06 [GATE] Safe evidence failure.** Claim: missing, stale, malformed, or unevaluable evidence yields an exact block instead of assumed acceptance or subject mutation. Applicability: conditional on any evidence defect. Pass: status and diagnostic identify the invariant and recovery path. Evidence: validator/status and worktree diff. On fail: open a process finding. Sources: E-2, E-4, E-13; EVAL-SC-06.
- [ ] **EVAL-CK-07 [GATE] Review-only authority.** Claim: the evaluator records findings and recommendations but changes no subject, disposition, scope, or user decision. Applicability: unconditional. Pass: report and worktree prove read-only review. Evidence: diff, dispatch, report, and disposition record. On fail: reject the report and open a Risk finding. Sources: E-1, E-7, E-11; EVAL-SC-07.
- [ ] **EVAL-CK-08 [REQUIRED] Actionable readable evidence.** Claim: sections, findings, checklist results, paths, commands, and recommendations are clear without private or visual context. Applicability: unconditional. Pass: a cold read can reproduce the issue and correction target. Evidence: rendered report inspection. On fail: open an Aesthetics or Usage finding. Sources: E-3, E-4, E-6, E-9; EVAL-SC-08.
- [ ] **EVAL-CK-09 [GATE] Full fresh revision review.** Claim: every materially changed subject has a new digest, fresh identities, complete sections, current ledger, and completed checklist. Applicability: conditional on material revision. Pass: no acceptance evidence is carried forward. Evidence: prior/current digests, identities, and reports. On fail: the current report is invalid. Sources: E-1, E-2, E-12–E-14; EVAL-SC-09.
- [ ] **EVAL-CK-10 [GATE] Reproducible findings and verdict.** Claim: direct evidence, false-positive checks, fingerprints, provenance, checklist results, and scoring reproduce every conclusion. Applicability: unconditional. Pass: independent rerun and derivation agree. Evidence: exact checks and validator output. On fail: the report is invalid. Sources: E-4, E-6–E-10, E-13; EVAL-SC-10.

## Closure

Coverage closure requires a terminal evidence result for every row. One evaluator report is conformant only when each applicable gate and required item is PASS; fluent prose, a valid file, or a plausible verdict cannot replace complete direct evidence.
