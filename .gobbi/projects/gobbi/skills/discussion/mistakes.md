## contract-preserving-inference-was-over-gated

`priority: high` · `domain: process` · `added: 2026-07-11` · `status: active` · `tags: [process, assumption]`

**What happened** — The manager treated a contract-preserving implementation inference as a user decision.
**Why it happens** — It confused research confirmation with authority classification.
**How to detect** — A question asks the user to approve a routine technical inference even though authoritative evidence resolves it inside accepted scope, trade-offs, and manager authority.
**Correct approach** — Apply the evidence-earned, contract-preserving inference and report it. Ask only when evidence conflicts or the choice changes design, scope, success criteria, destructive authority, publication, a waiver, a finding disposition, or another user-owned decision.
