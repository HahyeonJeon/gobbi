# Planning Checklist

Mode: evaluation coverage register. Run style: do-confirm. This source stays unchecked. Work a fresh filled copy and resolve each applicable item as PASS, FAIL with finding IDs, or N/A with inspected evidence. Acceptance requires PASS on every applicable item.

## Checks

- [ ] **PLAN-CK-01 [GATE] Locked-scope coverage.** Claim: all accepted Ideation obligations map to tasks and no task adds scope. Applicability: unconditional. Pass: bidirectional trace and scope diff close. Evidence: obligation ledger and task traces. On fail: halt Execution and open a Project finding. Sources: P-1, P-2, P-3; PLAN-SC-01.
- [ ] **PLAN-CK-02 [GATE] Role and authority fit.** Claim: each task's actor, skills, tools, context, and authority match its work. Applicability: unconditional. Pass: canonical skill and actual-writer checks succeed. Evidence: task role fields and authority records. On fail: open a Structure or Risk finding. Sources: P-4, P-8; PLAN-SC-02.
- [ ] **PLAN-CK-03 [GATE] Coherent state and handoffs.** Claim: each task starts and ends in a valid state and literal outputs match downstream inputs. Applicability: unconditional. Pass: stop-after-task and name-match reviews succeed. Evidence: handoff ledger. On fail: open a Consistency finding. Sources: P-4, P-6, P-9; PLAN-SC-03.
- [ ] **PLAN-CK-04 [GATE] Acyclic dependency and writer order.** Claim: requires edges encode all file, resource, decision, and interface dependencies; parallel work is read-only. Applicability: unconditional. Pass: topological sort and overlap matrix agree with plan order. Evidence: graph and resource map. On fail: open a Structure or Risk finding. Sources: P-5–P-7; PLAN-SC-04.
- [ ] **PLAN-CK-05 [REQUIRED] Resource verification.** Claim: applicable performance, capacity, external-call, and cost commitments have bounded measured tasks. Applicability: conditional on such Ideation obligations. Pass: each obligation has an isolated task and runnable measurement. Evidence: trace and command. On fail: open a Performance or Cost finding. Sources: P-3, P-4, P-11; PLAN-SC-05.
- [ ] **PLAN-CK-06 [GATE] Failure and rollback.** Claim: task failure or interruption leaves a coherent recoverable state. Applicability: unconditional. Pass: failure routes, rollback, and commit boundaries are executable. Evidence: injected-failure reasoning and task contract. On fail: open a Risk finding. Sources: P-4, P-9; PLAN-SC-06.
- [ ] **PLAN-CK-07 [GATE] Harm and external action gates.** Claim: destructive, privileged, sensitive, external, dependency, and publication work is isolated and authorized. Applicability: conditional on matched tasks. Pass: real-context authority and reversal evidence exist. Evidence: user decision and actual-writer proof. On fail: halt and open a blocking Risk finding. Sources: P-4, P-5, P-8; PLAN-SC-07.
- [ ] **PLAN-CK-08 [REQUIRED] Inclusion and locale tasks.** Claim: every applicable access or locale obligation has implementation and verification work. Applicability: conditional on accepted obligations. Pass: trace closes to concrete files, outputs, and checks. Evidence: task coverage ledger. On fail: open a Usage finding. Sources: P-3, P-4; PLAN-SC-08.
- [ ] **PLAN-CK-09 [GATE] Compatibility and source preservation.** Claim: migrations, consumers, source-before-delete, rollback, and go/no-go order are complete. Applicability: conditional on existing consumers or lifecycle change. Pass: compatibility and CRUD maps close. Evidence: task graph and source union. On fail: open a Consistency or Risk finding. Sources: P-5, P-9, P-10; PLAN-SC-09.
- [ ] **PLAN-CK-10 [GATE] Cold task executability.** Claim: every task is self-contained, placeholder-free, runnable, traceable, and fails a cosmetic result. Applicability: unconditional. Pass: cold-task reads and verification probes succeed for every task. Evidence: isolated task audit. On fail: halt Execution and open a Usage or Project finding. Sources: P-4, P-8, P-11; PLAN-SC-10.
- [ ] **PLAN-CK-11 [REQUIRED] Observable-outcome decomposition.** Claim: every task is an inspectable end-to-end outcome or a named enabler for one. Applicability: unconditional. Pass: the task-to-outcome map closes with no pure-layer task lacking a named unlocked outcome. Evidence: task-to-outcome map. On fail: open a Structure or Project finding. Sources: P-12; PLAN-SC-11.
- [ ] **PLAN-CK-12 [REQUIRED] Reference-class estimates.** Claim: each task estimate cites comparable completed work or states its uncertainty. Applicability: unconditional. Pass: every estimate has a reference class or an explicit uncertainty; none is a basis-free point value. Evidence: task estimate fields. On fail: open a Project or Performance finding. Sources: P-13; PLAN-SC-12.
- [ ] **PLAN-CK-13 [REQUIRED] Observable re-plan triggers.** Claim: near work is committed as full tasks while far work is an explicit user-approved deferral, and every load-bearing assumption has an observable signpost and a named continue/revise/stop/escalate response. Applicability: conditional on load-bearing assumptions or multi-horizon work. Pass: the assumption-signpost-response register closes with no judgment-only trigger. Evidence: assumption register. On fail: open a Risk or Project finding. Sources: P-14; PLAN-SC-13.

## Closure

Coverage closure requires inspected evidence for all rows. Planning acceptance requires every applicable gate and required row to PASS; an assigned owner or deferred in-scope requirement does not count as acceptance.
