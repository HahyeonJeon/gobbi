# Authoring

Authoring routes writing design, planning, implementation, and non-gating review to focused operations. Use it when at least one
direct Authoring child applies, and load every direct child whose applicability sentence matches the current work.

## Child Skills

| Child skill | Type | Load when |
|---|---|---|
| [`authoring-execution`](authoring-execution/SKILL.md) | operation | Use it when one accepted task has a settled writing design and a writer frontier that includes durable prose. |
| [`authoring-ideation`](authoring-ideation/SKILL.md) | operation | Use it when a bounded topic has an unresolved material writing-design choice. |
| [`authoring-planning`](authoring-planning/SKILL.md) | operation | Use it when scope and direction are defined for writing work but that work still needs decomposition, grouping, order, and dispatch. |
| [`authoring-review`](authoring-review/SKILL.md) | operation | Use it after one exact stable writing subject is ready for independent review and before an acceptance or workflow decision. |
