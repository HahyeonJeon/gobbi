# TypeScript

TypeScript routes language work and reviews to focused implementation, preference, testing, packaging, delivery, and toolchain skills. Use it when a task changes, studies, or reviews TypeScript source, types, configuration, tests, packages, or delivered commands.

This root owns navigation only, and every task selects each applicable child.

## Child Skills

| Child skill | Type | Load when |
|---|---|---|

| [`typescript-packaging`](typescript-packaging/SKILL.md) | operation | Use it when creating, changing, validating, or publishing package exports, declarations, package-backed commands, archives, or compatibility claims. |
