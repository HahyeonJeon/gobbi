# Wrap-up Checklist

Mode: evaluation coverage register. Run style: do-confirm. The source stays unchecked. Work a fresh filled copy in one evaluator report. Each applicable row resolves PASS, FAIL with finding IDs, or N/A with inspected evidence. Acceptance requires all applicable rows to PASS.

## Checks

- [ ] **WRAP-CK-01 [GATE] Scope-complete closure.** Claim: the closure covers every agreed result and only this session's material. Applicability: unconditional. Pass: scope, artifacts, staging, project delta, and handoff reconcile. Evidence: closure ledger and exact paths. On fail: open a Project finding. Sources: W-1, W-2, W-9; WRAP-SC-01.
- [ ] **WRAP-CK-02 [GATE] Cold-resume handoff.** Claim: a new manager can resume from the handoff without private context or stale Git facts. Applicability: unconditional. Pass: all nine sections are usable and every unresolved item has a reason and action. Evidence: cold read and Git inspection. On fail: open a Usage finding. Sources: W-9, W-10; WRAP-SC-02.
- [ ] **WRAP-CK-03 [GATE] Total typed-source accounting.** Claim: every expected typed staging source has exactly one stable outcome and empty staging remains valid. Applicability: unconditional. Pass: inventory, hashes, source identities, and manifest rows reconcile. Evidence: filesystem and inventory. On fail: open a Structure or Consistency finding. Sources: W-2, W-3, W-4, W-6; WRAP-SC-03.
- [ ] **WRAP-CK-04 [GATE] Manifest-owned structure.** Claim: every durable mutation is legal, preimaged, and mapped one-to-one with the actual project delta. Applicability: unconditional. Pass: row/result bijection, live frontmatter, explicit strict archive, archive-body identity, successor/non-successor lifecycle, and scoped active-file link checks pass. Evidence: manifest, preimages, diff, no-argument live validation, exact archive-path validation, body comparison, and active link inputs. On fail: open a Structure or Consistency finding. Sources: W-4, W-5, W-6, W-7, W-8; WRAP-SC-04.
- [ ] **WRAP-CK-05 [REQUIRED] Bounded mechanics.** Claim: inventory, rendering, shared-file assembly, apply, and verification are deterministic and proportionate. Applicability: conditional on a non-empty batch or material shared destination. Pass: stable order and operation evidence show bounded work. Evidence: command and timing or operation-count results. On fail: open a Performance finding. Sources: W-4, W-6, W-8; WRAP-SC-05.
- [ ] **WRAP-CK-06 [GATE] Drift and recovery.** Claim: preimage drift makes zero writes, interruption is located, and rerun is idempotent. Applicability: unconditional. Pass: direct failure-path evidence proves safe stop and stable rerun. Evidence: hashes, row receipts, and rerun result. On fail: open a Risk finding. Sources: W-4, W-6, W-8; WRAP-SC-06.
- [ ] **WRAP-CK-07 [GATE] Authority and data safety.** Claim: writes stay inside the isolated worktree, protected data is not copied, and the assistant performs no Git finalization. Applicability: unconditional. Pass: resolved paths, content review, and Git evidence close. Evidence: topology, paths, status, and authority record. On fail: open a blocking Risk finding. Sources: W-2, W-4, W-5, W-6, W-10; WRAP-SC-07.
- [ ] **WRAP-CK-08 [REQUIRED] Accessible durable handoff.** Claim: the handoff is navigable, plain, locale-clear, and independent of visual position. Applicability: unconditional. Pass: outline, links, dates, commands, and terminology pass a cold read. Evidence: rendered document inspection. On fail: open a Usage or Aesthetics finding. Sources: W-9; WRAP-SC-08.
- [ ] **WRAP-CK-09 [GATE] Reversible lifecycle and Git boundary.** Claim: true supersession is reciprocal; retirement, completion, and abandonment have no invented successor; every terminal record uses a compatible reason and exact project-root archive; and unmerged work remains recoverable. Applicability: conditional on lifecycle change or deferred publication. Pass: lifecycle fields, destination, branch, worktree, and authority agree. Evidence: records, exact archive-path validation, and Git topology. On fail: open a Consistency or Risk finding. Sources: W-7, W-10; WRAP-SC-09.
- [ ] **WRAP-CK-09A [GATE] Frozen archive-body link.** Claim: an expected unresolved outbound relative link inside a terminal archive does not fail link resolution only when the complete body and exact link text remain byte-identical and every strict, lifecycle, and actual-tree proof passes. Applicability: a terminal body contains a relative link; otherwise `n/a:<property>` with inspected body evidence. Pass: the body comparison and separate archive proofs pass, and the archive body is absent from scoped link inputs. Evidence: active preimage, archive body, link input register, strict output, lifecycle fields, and actual tree. On fail: open a Consistency or Risk finding. Sources: W-7, W-8; WRAP-SC-09A.
- [ ] **WRAP-CK-09B [GATE] Active inbound carrier.** Claim: every active inbound carrier is repointed to the archive path and remains link-gated. Applicability: a terminal move has an active inbound carrier; otherwise `n/a:<property>` with an inspected old-path search. Pass: no active old path remains, every carrier has a manifest row, and scoped links pass. Evidence: old-path search, carrier preimages/results, manifest, and link output. On fail: open a Consistency or Risk finding. Sources: W-7, W-8; WRAP-SC-09B.
- [ ] **WRAP-CK-09C [GATE] Live namespace link safety.** Claim: every changed Markdown file in a live namespace move receives the full link-resolution gate without the archive-body exclusion. Applicability: a live area split, merge, or rename; otherwise `n/a:<property>` with inspected mutation-class evidence. Pass: all changed live inputs are present and their links resolve. Evidence: mutation class, changed-path set, link input register and output, and residual search. On fail: open a Consistency or Risk finding. Sources: W-8; WRAP-SC-09C.
- [ ] **WRAP-CK-10 [GATE] Actual-result fresh proof.** Claim: both fresh evaluators reviewed the actual post-promotion tree, including every explicitly validated and body-compared new archive, all changed active link carriers, and matching handoff bodies; every material change received a new full review. Applicability: unconditional. Pass: subject hashes, report identities, archive and handoff body comparisons, live/archive guards, active-link evidence, and dispositions agree. Evidence: reports, body digests, scoped link input register, and exact validator output. On fail: reject closure and open a Project or Risk finding. Sources: W-8, W-9, W-11; WRAP-SC-10.

## Closure

Coverage closure requires a terminal evidence result for every row. Wrap-up is accepted only when each applicable gate and required item is PASS; an intended manifest, assistant report, or empty directory cannot replace direct actual-tree proof.
