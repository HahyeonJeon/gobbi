# CLI Security

This nonproduction skeleton reserves the CLI assurance operation for an exact change and its trust boundaries.
It owns threat and control judgment, evidence routes, residual uncertainty, stop states, and recovery duties.

A fresh Operation Skill Writing pass will replace every placeholder below. It must retain this trigger and
must not implement TypeScript controls, execute tests, produce artifacts, use credentials, or deliver them.
