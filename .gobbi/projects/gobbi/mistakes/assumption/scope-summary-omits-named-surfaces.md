# Repeat every user-named scope surface

## What happened

The manager replaced the user's concrete multi-surface scope with an umbrella phrase about every live surface. The summary omitted skills and the plugin package, so the user had to restate those required surfaces.

## Why it happens

The manager assumed the earlier table made omitted names obvious. Generic compression hides whether each named requirement survived and forces the user to infer scope at the later authority checkpoint.

## Correct approach

Repeat every locked surface explicitly in scope confirmations and delegation briefs before using an umbrella phrase. List skills, agents, plugins, bridge commands, validators, and templates again. Relying only on an earlier table is insufficient because the later confirmation is the authority checkpoint the user sees.

## How to detect

A user names several required surfaces, but a later scope prompt says only "all surfaces" or "everywhere" instead of repeating each surface.
