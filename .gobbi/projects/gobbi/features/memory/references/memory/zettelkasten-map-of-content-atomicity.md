# Evergreen notes should be atomic (+ Maps of Content)

## Insight
When atomic notes accumulate, the discipline is NOT to blob them together but to write a Map-of-Content / structure note that indexes and synthesizes the cluster while each atomic note keeps its own identity and full content. Atomic notes should stay atomic.

## Reason
This is the exact safe-merge mechanic for gobbi's uniform compaction: a consolidated file preserves each source as its own full section (atomic-section preservation), so a merge synthesizes without diluting — the mitigation that makes merging high-value `mistakes`/`rules` safe after the user removed the type exemption. Invoke when defending atomic-section preservation over a flatten-to-summary merge.
