# Planning fallacy and reference-class forecasting

## Insight
The planning fallacy is a systematic underestimation of time/cost/risk even when historical data is available; reference-class forecasting (Kahneman/Flyvbjerg) debiases it by predicting from the distribution of similar past projects — the outside view — rather than the case's inside-view details.

## Reason
A genuinely new principle for the planning skill: size and scope from comparable past work. In this repo the "reference class" is project memory (past `plans/` and `mistakes/`), so Procedure P6 (reference-class estimation) has concrete inputs.
