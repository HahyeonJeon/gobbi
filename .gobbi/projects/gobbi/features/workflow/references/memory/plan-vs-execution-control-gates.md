# NASA SE handbook — decision/control gates

## Insight
The NASA Systems Engineering Handbook structures a project around Key Decision Points / control gates — milestone reviews with explicit entrance and success criteria — that confirm the plan against actual execution before proceeding. Verification is anchored to defined gates, not authored ad hoc at each step.

## Reason
Strengthens the generic skill's Principle 3 (a work package is verified as one unit) and Procedure P5/P8 (anchor verification): each task's acceptance is a gate with stated pass criteria, mirroring the "verification is anchored, not authored" craft. Surfaced by the Codex proposer.
