# GPT-5.6 explicit Sol identifier

## Insight

The `gpt-5.6` alias routes to `gpt-5.6-sol`, which OpenAI identifies as the flagship-capability variant. Use the explicit Sol identifier when deterministic model selection matters.

## Reason

Gobbi is intentionally replacing machine-dependent inheritance with an explicit repository policy.
