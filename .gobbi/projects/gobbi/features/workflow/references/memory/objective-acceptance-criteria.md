# Acceptance criteria and Definition of Done

## Insight
Good acceptance criteria are specific and measurable, and each maps to an executable check that objectively confirms pass/fail (SMART); acceptance criteria are per-task while the Definition of Done is the project-wide "complete" bar every task also meets.

## Reason
This is the craft under the gobbi `verifies:` field and the reason verification is folded INTO generic Principle 3 ("a work package is bounded enough to verify as one unit") rather than being a standalone principle.
