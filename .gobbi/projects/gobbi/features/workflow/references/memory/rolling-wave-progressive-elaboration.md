# Rolling wave planning and progressive elaboration

## Insight
PMBOK's rolling-wave technique plans imminent work in detail and defers detail on later work until information arrives — a deliberate answer to how much to fix up front versus defer.

## Reason
Underpins the generic skill's Principle 5 ("a plan is a forecast") and Procedure P7 (decide the elaboration horizon) — the plan fixes detail where it is knowable and marks the rest coarse on purpose.
