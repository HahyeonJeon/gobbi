# Work Breakdown Structure — the 100% rule

## Insight
A decomposition must cover 100% of the scope and nothing outside it: the sum of the children equals the parent, and no unit falls outside the actual scope.

## Reason
This is the completeness-and-boundary property behind the generic planning skill's Principle 1 ("coverage without gaps or double ownership") — a task set that under-covers drops requirements and one that over-covers is scope creep.
