# WBS decomposition — the work-package bar

## Insight
Decomposition stops when each work package is clear enough to estimate, assign, and track — an objective stop rule, not a fixed depth or a size guess.

## Reason
Gives the generic planning skill's Principle 3 + Procedure P3 an objective termination condition, replacing the current doc's "medium granularity (~2-5 files)" heuristic with a testable bar.
