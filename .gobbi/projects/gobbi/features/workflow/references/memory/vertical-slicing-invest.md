# Vertical slicing vs horizontal layering; INVEST

## Insight
Slicing work into end-to-end increments (each independently valuable and testable) satisfies INVEST — Independent, Negotiable, Valuable, Estimable, Small, Testable — whereas slicing by architectural layer (UI task, DB task) fails Independent and Valuable because no layer is verifiable on its own.

## Reason
This is the task-quality test the current planning doc lacks; it becomes the generic skill's Principle 2 ("slice by observable outcome, not layer") and the P3 slicing check.
