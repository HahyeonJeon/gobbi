# Git evidence commands for branch audits

## Insight

`git diff`, `git show`, and `git worktree` are authoritative evidence sources for branch deltas, commit content, and worktree isolation.

## Reason

Use this insight when auditing previous branch scope or session claims. Branch-quality conclusions should rest on git command evidence rather than session summaries or proxy claims.
