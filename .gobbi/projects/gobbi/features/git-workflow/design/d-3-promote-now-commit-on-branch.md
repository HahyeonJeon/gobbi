# D-3 — NEW absorbed: commit-on-branch for Preparation promote-now

## Decision

Extend `preparation/SKILL.md` narrow-exception promote-now path to run a worktree-branch commit as its closing step:

```
git -C "$worktreePath" add <promoted-files>
git -C "$worktreePath" commit \
  -m "chore(skills): promote {slug} generated by preparation iter{n}" \
  -m "AI-Provenance-Record: gobbi://session/{session-id}/task/preparation-promote-now-iter{n}"
```

**Partial-failure rollback**: if `git commit` fails post-copy, manager MUST `git -C "$worktreePath" rm` the copied file and surface to user via AskUserQuestion before re-attempt.

## Rationale

T1-I-3: the narrow exception is already a sole-writer violation; commit-on-branch is the structural completion. `-C "$worktreePath"` is explicit about which tree. The canonical `AI-Provenance-Record` trailer form is `gobbi://session/{session-id}/task/{task-id}` per `git/conventions.md:118` (verified iter2 + iter3 whole-file scan). Rollback semantics close iter1 R2 (partial promotion failure) and the `1829fa3`-style failure mode.

## Trade-offs considered

- Alternative trailer form — rejected: requires separate Scope Contract item; current task-id slot is expressive enough
