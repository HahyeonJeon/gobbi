# Scope spine — three-tier scope with priority order

## Context

The Ideation leader surfaced the scope choice: should the session cover just the standard +
content rewrite, or also the skills/principles encoding, or also organization & navigation?

## Question

Primary scope among: (1) standard + content rewrite, (2) organization & navigation,
(3) skills/principles encoding.

## Options considered

- **Option A:** standard + content rewrite only (primary deliverable, minimal scope).
- **Option B:** standard + all three tiers in one session (ambitious, risk of big-bang).
- **Option C:** cover all three, with stated priority order (bottom-up, each tier verified).

## User decision

"Cover all three; priority = (1) Standard + content rewrite [primary], (2) skills/principles
[optional, not mandatory], (3) organization & navigation."

## Implication

All three tiers are In-Scope. Priority order:
- Tier 1 (primary): standard authoring + conformance wave + prose-quality wave — must ship.
- Tier 2 (optional): minimal mechanical grep gate extended to `features/`; no Principle-13
  surgery or new eval perspective (deferred).
- Tier 3 (tertiary): light nav wave verifying feature README.md Subdirectories sections; runs
  last, must not block tier-1.

The deferred-heavier-enforcement backlog was filed (evaluation perspective + Principle-13 encoding)
with the explicit note: "avoid unnecessary change / don't think deeply."
