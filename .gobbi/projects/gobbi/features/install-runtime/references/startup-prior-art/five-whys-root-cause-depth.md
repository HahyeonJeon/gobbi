# Five Whys (Toyota) root-cause depth

## Insight
Iterative "why" chains reach root cause, and the number of whys is not fixed — it may be higher or lower
depending on the complexity of the problem, stopping when fixing the cause would make the failure disappear.

## Reason
Supports P3 depth-by-need over a fixed limit, and it is the exact tool Topic 2.2's root-cause probe and A4's
uncertainty allocation already reach for. Its stop-at-root discipline grounds the vague-cap-vs-evidence-led
distinction: drill while each answer is concrete and yields new signal, stop when it stops moving. Invoke when
distinguishing evidence-led depth from badgering a vague answer.
