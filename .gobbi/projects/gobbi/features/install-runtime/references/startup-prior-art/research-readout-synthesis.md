# User-research readout / synthesis

## Insight
A readout synthesizes findings into a tight, narrative summary that summarizes and points rather than dumping
raw notes; synthesis clusters raw data into a few solid insights.

## Reason
Sets the SHAPE of the P1 phase document — a synthesized readout, not a copy of the raw discussion log. This
maps onto the startup skill's existing synthesis-in-sections heuristic and its "no raw audit promoted"
discipline, and it is what the new fidelity check grades (readout, not raw dump). Invoke when defining the
phase-document sections and the fidelity check.

## Source
- https://miro.com/research-and-design/research-synthesis/
- Affinity-mapping / readout practice (aim for a small set of solid insights, kept tight)

## Excerpt
"Research synthesis is the process of combining findings ... to identify patterns, themes, and insights ...
the readout summarises key findings ... creating a clear narrative."
