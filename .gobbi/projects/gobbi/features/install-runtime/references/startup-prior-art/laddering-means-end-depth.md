# Laddering (means-end) interview technique

## Insight
Laddering uses repeated "why" follow-ups to climb attribute → consequence → value; a session runs a few
chains, each of variable depth, and the depth is driven by the participant's answer rather than a preset
question count.

## Reason
Validates P3's unbounded, evidence-led Level-3+ follow-up chains under a topic: depth follows the answer, not
a fixed limit. Invoke when designing the ad-hoc follow-up allowance and its evidence-led (not badgering)
character.
