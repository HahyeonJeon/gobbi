# BABOK 4.3 Confirm Elicitation Results

## Insight
After each elicitation event the analyst documents the result, checks it for accuracy and consistency
against previously documented information, and shares it with participants to confirm shared understanding
before proceeding — so errors and omissions are resolved early rather than after the next phase builds on them.

## Reason
This is exactly the startup per-phase document contract (P1): at each interview phase close, synthesize the
phase, check it against the running record (the cross-topic consistency pass), and get the user to confirm —
not one late pre-promotion recap. Invoke when designing the phase-close write-and-confirm step.
