# Survey design — one question per page vs multiple

## Insight
Paging (one question per screen) versus scrolling makes little difference to completion on desktop;
one-per-page reduces visual overwhelm but adds friction (extra clicks, boredom, lower satisfaction) — and
cognitive load per question matters more than page layout.

## Reason
The genuine value of one-question-per-turn is cognitive-load / classification clarity, and the startup ledger
already delivers that structurally via per-answer tagging (`recording.md §2`). So the mechanical rule is not
what carries the benefit, and removing it (P2) preserves the value while dropping the friction. Invoke when
arguing the pacing rule can go without loss.
