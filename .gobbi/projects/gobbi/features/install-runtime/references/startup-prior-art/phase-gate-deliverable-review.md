# Phase-gate / stage-gate deliverable and gate review

## Insight
Each phase produces defined deliverables, and a gate review checks those deliverables against criteria; the
project cannot enter the next phase until it clears the gate.

## Reason
Grounds the P1 "graded obligation" framing: the phase-result document is the phase deliverable and the user
confirmation is the gate the P6.5 bundle grades. It mirrors the startup skill's existing Topic-4→5
problem-before-solution premise gate. Invoke when designing the phase-close confirmation as a gate, not just a
written note.

## Source
- https://www.smartsheet.com/phase-gate-process
- Also HHS EPLC Stage Gate Review Practices Guide (deliverables + recommendation outputs)

## Excerpt
"Products can't move to the next phase until they clear the gate ... each gate contains the criteria and
results that must be met for the project to move to the next phase."
