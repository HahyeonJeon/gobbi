# Authoring Tips

## "The same templates" means the record contract

**Context:** A user asks one skill's `templates/` to be the same as another's, while each skill still has its
own design headings.

**Tip:** Match the file names, the Requirements block, and the rule that a Discussion topic links to the Design
heading that holds the decision. Keep the skill's own headings and procedure. A byte copy of the source
templates also copies that skill's headings, such as Class and Function Design, into the wrong domain.

**Application:** Confirm that reading with the user before editing. When the source skill has no local
`ontology.md`, deleting the target's copy is a separate edit: retarget every consumer link, then project the
plugin package.
