# Domain skill families completed

**Completed at:** 2026-09-06T13:30:00Z

## Changes

- Replaced generic Ideation, Planning, Study, Execution, and Evaluation skills with four-child
  navigation-only domain families: [Coding](../design/feature/coding-skill-family.md),
  [Authoring](../design/feature/authoring-skill-family.md), and
  [Design](../design/feature/design-skill-family.md). Each family owns ideation, planning, execution,
  and non-gating review. The removed top-level skills have no alias.
- Moved study, discussion, the design ladder, and the indexed ideation result into each domain
  ideation skill, and moved decomposition into each domain planning skill. Coding Review remains
  non-gating and no longer carries a Coverage Account.
- Recorded Design Ideation as two image passes, structure then direction, with listed PNGs as
  illustration and written Design headings as authority.
- Marked Generic Evaluation and `skills/evaluation/` removed. Cowork still has a user-called
  `evaluate` phase. The evaluator load map stays stale until Evaluation is redesigned.
