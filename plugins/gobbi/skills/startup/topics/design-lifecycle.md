# Design Lifecycle Topics

Design Lifecycle owns visual-production direction, critique, approval, handoff, quality evidence, adaptation,
evolution, and retirement. Use this common bank for every visual artifact form and add an overlay only when
accepted evidence activates it. Keep software and Project structure in Design and Specification, actor-visible
promises in Product Lifecycle, and technical build and release mechanisms in Development Lifecycle.

## Overlay Banks

| Bank | Select when accepted evidence shows |
|---|---|
| [UI](design-lifecycle/ui.md) | Accepted evidence identifies an interactive visual interface with states, controls, feedback, or responsive behavior. |
| [Presentation](design-lifecycle/presentation.md) | Accepted evidence identifies a slide-based or sequenced visual presentation for live delivery or independent reading. |
| [Report](design-lifecycle/report.md) | Accepted evidence identifies a structured visual report for review, decision, reference, print, or recurring publication. |

Several overlays may apply to one visual artifact. Selection is evidence-based guidance, never a new Startup
subject or acceptance boundary. A comparable form without a matching overlay uses this adaptive common bank.

## Product

- [dl-artifact-audience] Who will view, use, present, review, or approve this visual artifact?

- [dl-artifact-purpose] What must the visual artifact help its audience understand, feel, decide, or do?

- [dl-use-context] In which environment, device, distance, time limit, or attention condition will the artifact be used?

- [dl-reference-fit] Which evidence-backed references best fit this Product's audience, purpose, and context?

- [dl-concept] Which central concept should organize the artifact's visual choices?

- [dl-theme] Which theme should carry that concept without changing the accepted Product meaning?

- [dl-color-vibe] Which color relationships and overall vibe fit the audience, purpose, identity, and accessibility needs?

- [dl-style] Which visual style should govern shape, decoration, density, tone, and emphasis?

- [dl-typography] Which typography roles, hierarchy, scale, and reading behavior must the artifact preserve?

- [dl-layout] Which layout system should organize content, hierarchy, rhythm, alignment, and whitespace?

- [dl-imagery] What role should photography, illustration, icons, diagrams, or other imagery play?

- [dl-imagery-rights] Which source, consent, license, attribution, or representation constraint applies to imagery?

- [dl-motion-purpose] When motion is relevant, what meaning, orientation, feedback, or emphasis must it provide?

- [dl-motion-restraint] Which motion would distract, mislead, cause discomfort, or add no useful meaning?

- [dl-visual-accessibility] Which contrast, color-independence, legibility, reading-order, text-alternative, or sensory needs shape the design?

- [dl-content-stress] Which longest, shortest, missing, dense, translated, or user-generated content must the visual design withstand?

- [dl-format-adaptation] Across required sizes, media, orientations, and formats, which hierarchy and meaning must remain stable?

- [dl-localization-adaptation] Which language, script, reading direction, symbol, culture, or locale difference changes the visual treatment?

- [dl-critique-focus] Which uncertain visual decisions need critique, from whom, and against which purpose or evidence?

- [dl-approval-criteria] Which concrete criteria and decision-maker determine that the visual artifact is approved?

- [dl-quality-oracle] What visual comparison, inspection, rehearsal, or audience evidence can disprove design quality?

- [dl-handoff-content] Which decisions, assets, states, variants, constraints, and evidence must accompany visual handoff?

- [dl-adaptation-limit] Which later adaptation may vary, and which concept, hierarchy, identity, or accessibility duty must not change?

- [dl-evolution-trigger] Which audience, content, platform, brand, or performance evidence requires this Product's visual design to evolve?

- [dl-retirement-disposition] When the visual artifact retires, what is archived, replaced, removed, or kept for historical use?
