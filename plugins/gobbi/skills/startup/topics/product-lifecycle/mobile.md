# Mobile Product Lifecycle Overlay

Select this overlay only from accepted mobile Product evidence. It owns actor-visible mobile operating-system,
permission, background, update, and device-state promises.

## Project

## Product

- Across accepted size, orientation, scene, or form changes, which in-progress task state and outcome remain correct?

- After the mobile operating system backgrounds, suspends, or terminates the Product, which in-progress work is restored, and what loss or recovery is visible?

- When a required permission is denied, revoked, or auto-reset, what remains usable and how is safe access restored?

- During a platform-mediated Mobile update, what remains usable and how does the consumer reach compatible state or safe recovery?
