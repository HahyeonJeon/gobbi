## Product

- From install through first usable launch, what trust, permission, failure, and repair behavior does the consumer observe?

- Across alternate entry, close, quit, background, second instance, and restart, which input and state remain correct?

- When local state is absent, corrupt, locked, incompatible, or left by a crash, what safe state opens and what recovery is offered?

- During an installed Desktop update, what remains usable, how is interruption recovered, and which support path applies?

- After uninstall or retirement, which local data is removed, retained, exportable, or recoverable?
