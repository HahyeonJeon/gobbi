# HTML/CSS Family Vocabulary

This file defines only the five project-specific terms retained by the family. Use ordinary HTML, CSS,
browser, accessibility, design, and testing words everywhere else.

## `semantic owner`

The skill responsible for a claim's meaning. In ordinary developer language, this is the claim owner.

## `owner-tagged`

Labeled with the responsible skill so the claim, record, evidence, or handoff cannot be mistaken for another
owner's work.

## `lifecycle envelope`

The shared subject and handoff record header used across applicable design, development, testing, and platform
work. In ordinary developer language, this is the shared lifecycle record, not a mandatory workflow dossier.

## `supersession`

Replacement of a prior record while preserving its history. A superseded record remains visible but is no
longer current.

## `evidence ceiling`

The strongest claim that the available evidence can support. Evidence must not be used for a broader
conclusion.
